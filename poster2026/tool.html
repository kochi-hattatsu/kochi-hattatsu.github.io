指示文づくりツール

AIに「こんなアプリを作って」と頼むための文章を作ります。分からないところは空のままで大丈夫です。

  1. その子のこと
  2. どうしたいか
  3. 作り方
  4. できあがり

ステップ1/4

その子のこと

書いた内容は、この画面の外には送られません。ただし、できた文章をAIに渡すとAIには伝わります。本名や学校名は書かないでください。

困りごと 1つの欄に1つ書きます。例: 困っていても周りに言えない
消しました。
持っている機器 作るときはパソコンが必要です。スマホやタブレットは、動きの確認や、子どもが使う機器になります。ラズパイは、アプリを一日中動かしておく小さなパソコンです(なくても作れます)。

パソコンがなくても、このまま進められます。作りたい内容をAIが確認して、必要な性能のパソコン探しを手伝う文章になります。

ステップ2/4

どうしたいか

困りごとごとに、どうなってほしいかを書きます。分からなければ、AIと相談して決められます。

困りごとがまだありません。このまま次へ進むと、AIと一緒に整理する文章になります。

ステップ3/4

作り方

最初から「分からない」が選んであります。そのままで大丈夫です。あとから変えられます。

アプリの形 発表者のアプリは「キャラが窓口」の形ですが、どの子にもこの形が合うとは限りません。
アプリを動かす小さなパソコン(ラズパイ) なくても作れるアプリは多いです。必要かどうかはAIに確認してもらえます。
声で読み上げる・話す機能

ステップ4/4

できあがり

下の文章は、ここで直接直せます。直したら「文章をコピー」を押してください。

前のページの答えを変えましたが、手で直した文章はそのまま残しています。

作業はパソコンで行います。スマホで作ったときは、文章をメールやLINEで自分に送ると、パソコンで開けます。

  1. パソコンで、Claude Code などの作業をしてくれるAIを開きます(Claude Code の公式ページ)。
  2. この文章を貼り付けて送ります。
  3. AIの質問に答えます。分からなければ「分からない」でOKです。
